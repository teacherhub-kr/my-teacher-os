# MY MUSIC CLASS — Google Apps Script 교사 전용 대시보드

기존 MY TEACHER OS와 원본 Google Sheets를 **개별 성적의 공개 노출 없이** 연결하는 방식입니다.

- **원본:** 이미 소유한 \`2026_2학기_음악_가변형_수업_수행평가_스케줄\` Google Sheets
- **비공개 조회:** 이 시트에 연결된 Google Apps Script 웹앱
- **사용 화면:** Teacher OS의 [교사 전용 화면 열기] 버튼
- **보안:** 웹앱 배포를 반드시 **나로 실행 / 나만 접근**으로 제한
- **Google Cloud:** 별도의 OAuth 클라이언트 ID나 직접 만든 OAuth 동의 화면은 불필요. 첫 실행 때 Google Apps Script의 기본 권한 승인만 필요
- **입력·저장:** 학생 점수, 명렬표, 원본 채점표의 수식·데이터를 쓰거나 수정하지 않음. 읽는 범위는 \`평가통합현황!A3:K18\`로 고정

## 한 번만 하는 실제 연결

**시트 소유자 Google 계정으로 진행하십시오.** 개인 계정 소유 자료라면 개인 계정으로 크롬에 로그인합니다. 학교 계정과 섞여 있는 경우 크롬 프로필을 구분하는 것이 좋습니다.

1. 원본 스케줄표를 엽니다. 상단에서 **확장 프로그램 → Apps Script**를 선택합니다.
2. 새로 열린 **이 시트에 연결된** Apps Script 편집기의 \`Code.gs\`에 [Code.gs](./Code.gs) 전체 내용을 붙여넣습니다. 기존 스크립트가 있을 경우 **덮어쓰지 마세요**. 대신 새 \`MusicDashboard.gs\` 파일을 만들고 내용을 넣으며, 동일한 이름의 함수가 없는지 확인합니다.
3. 왼쪽 \`+\` → **HTML** → 파일명 \`Index\`를 추가하고 [Index.html](./Index.html) 내용을 붙여넣습니다.
4. 프로젝트 설정에서 **앱 스크립트 매니페스트(appsscript.json) 표시**를 켜고 [appsscript.json](./appsscript.json)을 적용합니다. 기존 프로젝트에 스코프/설정이 이미 있다면 무작정 덮어쓰지 말고 **필요한 스코프만 합칩니다**. 신규 빈 프로젝트인 경우 파일 전체 교체가 가능합니다.
5. **저장**하고, 함수 선택에서 \`initializeDashboard\`를 실행합니다. Google의 Apps Script 권한 승인 창이 뜨면 **본인 계정**인지 확인하고 권한을 승인합니다. 출력에 \`classes: 15\`가 나오는지 확인합니다. 이 작업은 **Script Properties에 원본 시트 ID를 저장할 뿐**, 원본 시트의 셀을 수정하지 않습니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다. 아래 조건을 엄수합니다.
   - **다음 사용자 인증 정보로 실행:** 나(Me)
   - **액세스 권한이 있는 사용자:** 나만(Only myself)
   - \`모든 사용자/Anyone\`나 \`링크가 있는 모든 사람\`으로 절대 배포하지 마세요.
7. 배포가 끝나면 나온 \`https://script.google.com/macros/s/.../exec\` 주소를 복사합니다.
8. [MY TEACHER OS](https://teacherhub-kr.github.io/my-teacher-os/)에서 **음악 수행평가 · 교사 전용 대시보드 → 웹앱 주소 연결**을 열고 \`/exec\` 링크를 입력한 뒤 **주소 저장**을 누릅니다.
9. **교사 전용 화면 열기**를 클릭하여 2학년 9개 반, 3학년 6개 반의 1~4차 미채점 수치가 조회되는지 확인합니다. 원본의 합계와 대조합니다.

## 중요한 차이

- Google OAuth 웹 클라이언트를 새로 만들 필요는 없지만, **Apps Script가 시트를 읽도록 최초 권한을 승인하는 과정은 있습니다.**
- Teacher OS는 \`/exec\` URL만 **이 브라우저 localStorage**에 저장합니다. 웹앱 접속 시 Google 계정 인증은 Google이 처리합니다.
- \`/exec\` 주소를 알고 있다고 아무나 조회할 수 있는 구조가 아닙니다. **배포 권한이 ‘나만’인지 확인하는 것이 필수**입니다.
- 웹앱으로 읽은 학급별 집계는 **교사 전용 웹앱 안에서만** 보입니다. 공개 GitHub Pages Teacher OS로 성적·학생정보가 복사되지 않습니다.
- 원본의 \`미채점 0명\`은 수업 실시 또는 보충평가 완료 확정이 아닙니다.
- **3학년 1·2차는 1학기 참고 자료**, 3·4차가 2학기 수행평가입니다.
- 앞으로 원본의 학급 수·열·제목이 바뀌면 오류 메시지로 실패하도록 설계했습니다. 잘못된 수치를 정상처럼 표시하지 않습니다.

## 점검 및 문제 해결

- **‘접근 권한 없음’** → 배포한 Google 계정과 크롬 로그인 계정이 일치하는지 확인합니다. 개인 계정 소유면 개인 계정으로 로그인하세요.
- **‘초기 설정이 없습니다’** → 스크립트 편집기에서 \`initializeDashboard\`를 1회 실행합니다.
- **‘집계표 제목이 변경되었습니다’** → 원본의 \`평가통합현황!A3:K18\` 구조를 확인합니다. 기존 점수는 수정하지 마세요.
- **변경된 코드가 반영되지 않음** → Apps Script의 **배포 관리 → 편집 → 새 버전**으로 업데이트합니다. 코드를 저장하는 것만으로 기존 배포가 자동 업데이트되지는 않습니다.
- **교사용 화면이 열리지 않음** → 배포가 \`Only myself\`인지, 주소가 \`/exec\`인지, 팝업 차단 여부와 Google 다중 로그인 상태를 확인합니다.

## 한계: 사용자 계정 조작이 필요한 구간

연결된 Google Drive 도구는 스프레드시트를 읽을 수 있지만 **Apps Script 편집기 프로젝트 생성·권한 승인·웹앱 배포는 수행할 수 없습니다**. 따라서 이 저장소의 코드를 구현·검증하는 것과 **개인 계정의 실제 웹앱 배포 완료**는 별개입니다. 실제 배포 URL이 나오기 전에는 원본이 Teacher OS에 '자동 연결 완료'됐다고 보고하지 않습니다.
