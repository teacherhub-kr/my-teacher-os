# MY MUSIC CLASS · 음악수업 품질·시각자료·배포 표준 (2026-11-09 개정)

> **기준:** 'HTML이 작동한다'와 '좋은 중학교 음악수업이다'는 서로 다른 판정이다. 학생이 실제 음악을 듣고, 부르고, 연주하고, 만들어 보는 시간이 중심이다.
> 2026-11-09 사용자 제공 독립 감사 「음악수업 자료실 품질 개선 방향」을 반영해 구 규칙의 **9~10장면 강제 및 동일 카드 반복**을 폐기한다.

## 1. 수업 설계 선행 · 5줄 기획
각 수업에 대해 코드를 쓰기 **전에** 아래를 확정한다.
1. **중심 작품/실연**: 곡명, 작곡가/전승, 연주자·제작기관, 정확한 공식 영상/음원 URL, 선택 이유.
2. **핵심 학생 음악 활동**: 도입 2분 안에 소리 재생, 듣기/가창/기악/움직임/제작 중 무엇을 언제 얼마나 할지.
3. **학생 산출물**: 짧게 연주한 소리, 선택한 프레이즈, 만든 리듬, 표시한 악보 등 **음악적** 결과물.
4. **평가**: 개인별로 관찰 가능한 음악적 근거 2~3개, 변성기·장애·접근성을 고려한 대체 수행. 태도·성실성 채점 금지.
5. **실제 교실 운영**: 교사 PC + 전자칠판 + 스피커 기본. 필요 시 활동지 A4. 학생 개인 계정·성적·녹음 업로드 불필요.

## 2. 음악 활동량·시간 게이트
- 총 45분. **첫 2분 안에 실제 음악 또는 교사 실연을 듣는다**(클릭으로 재생, 자동재생에 의존하지 않음).
- **최소 23분은 실제 듣기·가창·연주·몸으로 리듬 표현·음악 제작**. '그럴 예정'이라는 문장만으로 충족했다고 판정하지 않는다. 교사용 지도안에 음악 활동분을 명시한다.
- 학생의 **필기 합계 최대 10분**. 반복 질문·텍스트 입력 10개를 수업 장면으로 채우지 않는다.
- **도입 + 핵심활동 1 + 핵심활동 2 + 정리**, 통상 4~5개의 의미 있는 단계. 과제에 맞으면 다른 단계 수도 허용. 10장면 강제 금지.
- 주 활동은 10~15분 이상 몰입할 수 있게 설계. 정확히 45분으로 합산하고 상황에 따른 속도 조절안을 제공.

## 3. 전자칠판용 시각 디자인
- 배경은 강한 대비가 있는 단색/절제된 표면. 파스텔 그라데이션·이모지 타이틀·모든 장면 같은 카드 묶음 지양.
- 제목 40~60px, 핵심 지시문 26~36px, 악보·음원·현장 영상은 화면의 **중심·가장 큰 영역**. 멀리서도 읽히는 명암 대비.
- 화면마다 메시지 하나. 과도한 스크롤, 상단 메뉴로 인한 화면 축소, 불필요한 교사용 안내/저작권 면책 문구의 학생 화면 노출 지양.
- 가창/기악에는 **실제 선율을 담은 보표/정확한 리듬 악보**, 높은 품질의 연주 장면. 자동 합성음이나 근거 없는 악보 사용 금지.
- 감상에는 **공식 실연 영상·사진·악기 구조·소리 구간별 감상 지도**, 리듬에는 편집 가능한 비트/말리듬·손뼉/악기 활동.
- 사진은 저작권·작가·라이선스가 확인된 이미지만 사용. 외부 이미지의 출처를 자료실 또는 교사용 자료에 표시. 임의 웹 이미지 저장·무단 재배포 금지.
- 영상은 유튜브 **공식 채널 원본**을 우선 재생 링크/허용된 플레이어로 연결. 임베드 제한·학교망 차단 시 원본 링크 제공. 임의 영상 ID를 만들지 않는다.

## 4. 권리·음원 우선순위
1. 학교에서 정당하게 이용할 수 있는 **출판사 교과서 음원**, 학교 내부 교사 화면에서만 이용. 공개 GitHub 저장소 업로드 금지.
2. **국립국악원·공식 악단·박물관·실연자** 등의 공식 게시 영상(링크 또는 제공된 공식 플레이어).
3. Wikimedia Commons·IMSLP 등 원문·라이선스·실연 품질을 확인한 공개 자료.
- **작곡 저작권과 녹음의 저작인접권은 별개**. 학교 수업 이용과 공개 재배포도 별개. 허가/근거 없는 음원·영상 파일 저장 금지.
- 원본 게시자가 임베드를 제한하면 우회하지 말고 링크 제공. 음원·영상을 직접 재생해 보는 테스트가 통과하지 않으면 재생 성공이라 보고하지 않는다.

## 5. 2022 개정 교육과정·평가
- 교육부 고시 제2022-33호 별책 12 음악과 원문에 대조한 **연주/감상/창작** 영역, 중학교 성취기준 코드·문구만 쓴다.
- 개인 활동·개별 피드백을 우선한다. 음악적 성취와 근거 중심 평가, 태도·협동성·성량·성격으로 배점하지 않는다.
- 학생 개인정보·성적·원본 Google Sheets·Apps Script·계정인증은 공개 수업 파일에 연결하지 않는다.

## 6. 단계별 제작·검수
1. **독립 감사:** 기존 카탈로그와 수업별 음악/활동 중복, 품질 문제 확인.
2. **기획 5줄 + 핵심 시제품:** 실연·사진/영상·악보가 들어간 핵심 화면을 실제 교사에게 보일 수 있어야 한다.
3. **전체 수업 완성:** 교사용·학생용·필요 시 A4 활동지. 학생 화면은 연주/재생/표현 중심.
4. **이중 검수:** 기능(브라우저·모바일·링크·미디어)과 교육 품질(활동 시간·악보 정확성·음악적 근거) **각각** 통과.
5. **배포:** PR→CI→main 병합→Pages 배포→공개 URL 재확인. 둘 중 하나라도 미확인이면 '완전 검증' 표시 금지.

## 7. AI 티 제거 점검표
- [ ] 이모지를 제목·장면명 앞에 기계적으로 붙이지 않는다.
- [ ] 학생 페이지에서 '실제/진짜', '합성음 아님', '미검증', '이름/학번을 쓰지 마세요' 등 기술·면책 문구를 지운다(필요한 내용은 교사용 안내와 크레딧으로 이동).
- [ ] 모든 단계가 동일한 '질문+텍스트박스' 구성이 아니다.
- [ ] 음악 자료를 첫 2분 안에 실제로 들려줄 수 있다.
- [ ] 핵심 활동 하나는 10~15분 이상이며 음악 활동이 23분 이상이다.
- [ ] 필기 10분 이내, 악보가 필요하면 정확한 보표/박자/쉼표가 보인다.
- [ ] 가창·기악은 선율과 연주를 갖고, 감상은 실제 소리 구간이 있다.
- [ ] 예상 답변은 중학생이 할 법한 구체적 말이고, '느낌이 좋았다' 같은 모호한 문구가 아니다.
- [ ] 사진·영상은 교육 목표에 직접 필요하고 출처/사용 조건을 증명할 수 있다.
- [ ] **교사용 지도안에 분별력 있는 교육적 판단·오개념 지도**가 있고, 학생용 화면에는 행정 문구를 과다 노출하지 않는다.

## 8. 카탈로그 하위 호환
`lessons/catalog.json`의 `schemaVersion=1`과 필수 필드는 유지하며 실제 배포된 수업만 `published`에 등록. `steps`는 실제 의미 있는 수업 단계 수로 표시하며 숫자 9~10을 요구하지 않는다. 6개 주제 카테고리의 균형보다 수업 품질이 우선이다.

## 9. 실증 한계 기록
GitHub Pages 접속·코드 구문 통과는 **교실에서 좋은 수업이 된다는 증거가 아니다**. 화면의 멀리서 보는 가독성, 학교 내부망 영상 재생, 학생 음악 활동량을 각각 독립 점검하고 미확인 상태를 정확하게 기록한다.
