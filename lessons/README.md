# MY MUSIC CLASS · 음악 수업자료실

Teacher OS의 `음악 수업자료실` 메뉴 및 첫 화면 바로가기로 접속합니다.

## 자료 구조
- `lessons/index.html`: 학년·영역·키워드 검색과 자료 카드.
- `lessons/catalog.json`: 등록한 **완성 수업**만 담는 단일 원장.
- `lessons/<lesson-id>/index.html`: 개별 수업 화면과 미디어. 서로 독립적으로 관리.
- 1호 자료: `orchestra-timbre` — 중2 감상, 45분, 사진/음원 14종, 9장면, 교사 설명 토글.

## 새 수업 등록 절차
1. 학년, 적용 교육과정, 성취기준, 학습 목표, 수업 시수에 맞는 수업을 제작한다.
2. 별도 폴더에 수업 HTML과 실제 사용 가능한 미디어를 배치하고, 출처 및 이용조건을 기록한다.
3. 기존 오케스트라 수업에 있던 **교사 설명 보기/숨기기**(기본 숨김, 재클릭 닫기, 장면 이동 시 갱신)를 공통 기능으로 유지한다.
4. 브라우저에서 실제 사진 표시, 음원 로드 및 재생, 영상 버튼, 퀴즈, 모든 장면, 교사 설명, 되돌아가기 링크를 테스트한다.
5. 검증을 통과한 수업만 `catalog.json`에 `status: published`로 추가한다. 초안은 자료실에 노출하지 않는다.
6. 공개 저장소에 학생 개인정보, 개별 평가·성적, 학교 내부문서를 넣지 않는다.

## 이용 참고
- 수업자료실 목록은 `catalog.json`에서 자동 구성합니다. 검색은 제목·설명·학년·교육과정·태그를 대상으로 합니다.
- 제3자 영상은 YouTube 게시자나 학교 네트워크의 임베드 제한이 있을 수 있습니다.
- 음악 수업자료실과 기존 Teacher OS는 독립적으로 운영하여 학교 업무 기능에 영향이 가지 않도록 합니다.
